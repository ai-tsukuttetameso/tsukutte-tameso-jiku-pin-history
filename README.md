# 時空ピン — 日本史の舞台を地図で当てるクイズ

年代や出来事の手がかりから、起きた場所を日本地図で当てるブラウザゲームです。

**[ブラウザで遊ぶ](https://ai-tsukuttetameso.github.io/tsukutte-tameso-jiku-pin-history/)**

- 全100問。時代・年代で絞り込み、5/15/30問または1〜100問の自由入力。
- 1問60秒。説明は10・20・35秒で追加、45秒でヒントが使えます。
- 正解に近く、早く答えるほど高得点。距離最大800点＋速さ最大200点。
- 近く答えられた問題を次の旅から除く設定があります。
- 学習記録と途中の旅はブラウザ内に保存。端末をまたぐ同期はありません。

## 動かし方

ビルド不要。このフォルダで `python3 -m http.server 8000` を実行し、localhostの8000番を開いてください。

地図・問題・処理は同梱されています。Google Fontsを読み込めない場合もシステムフォントで動作します。外部AI APIキーや地図タイルAPIは不要です。

## データと注意

問題と出典URLはquestions.jsに収録しています。正解位置は史跡や出来事の代表地点であり、測量上の厳密な地点ではありません。専門家による全件監修は実施していません。

地図はNatural Earthに由来する日本本土・北海道の簡略図です。離島等を省略しています。出所・ライセンスはassets/MAP-LICENSE.txtを参照してください。
